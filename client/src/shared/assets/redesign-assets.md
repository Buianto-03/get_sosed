# Ресурсы редизайна

Карта ресурсов для экранов GETSOSED по опубликованному макету. Фото находятся в client/public и доступны приложению по пути от корня сайта.

## Фотографии

| Использование | Локальный файл | Кадрирование |
| --- | --- | --- |
| Баннер главной и «О нас» | client/public/mainPhoto.jpg | Широкий контейнер, object-fit: cover; начинать с центра, при узком экране держать интерьер и диван в видимой области. |
| Карточка «Светлая квартира рядом с парком», галерея | client/public/images/2pic.jpg | Карточка — широкая обрезка по центру; галерея — cover, не растягивать. |
| Карточка «Квартира с просторной кухней», галерея | client/public/images/1pic.jpg | Карточка — широкая обрезка; если в конкретном контейнере виден водяной знак, использовать нейтральную заглушку. |
| Карточка «Жильё недалеко от центра», галерея | client/public/images/kvartira-moskva-bratskaya-ulica-2249903312-1.jpg | cover, центр; проверять область кадрирования на маленькой карточке. |

Эти изображения уже входят в репозиторий и подходят для локальных демонстрационных данных. На части объявлений видны сторонние водяные знаки, поэтому перед использованием в публичном production их нужно заменить фотографиями с подтверждёнными правами. Не использовать в новом макете welcomePageFirst.jpg и welcomePageSecond.jpg: на них заметен посторонний брендинг. logo.png также не совпадает с актуальным знаком сайта; знак дома собирать из иконки и текста GETSOSED.

## Шрифт

- Семейство: Inter, веса 400, 500, 600 и 700.
- Локальное размещение: client/public/fonts/Inter-Variable.ttf и client/public/fonts/OFL.txt.
- Источник: официальный репозиторий Google Fonts, каталог Inter; лицензия SIL Open Font License.
- Подключение через @font-face выполнить вместе с базовыми стилями в K01, чтобы P02 не меняла оформление существующих страниц.

## Иконки

В проекте уже установлена библиотека react-icons. Для нового интерфейса использовать единый набор Lucide из react-icons/lu; новую зависимость добавлять не нужно.

| Назначение | Иконка |
| --- | --- |
| Бренд и главная | LuHome |
| Поиск | LuSearch |
| Фильтры | LuSlidersHorizontal |
| Избранное | LuHeart |
| Меню и закрытие | LuMenu, LuX |
| Создание объявления | LuPlus |
| Сообщения | LuMessagesSquare |
| Профиль | LuUser |
| Местоположение | LuMapPin |
| Комната и фотографии | LuBedDouble, LuCamera |
| Назад и подтверждение | LuArrowLeft, LuCheck |
| Ошибка | LuAlertTriangle |

Цвет и размер задаёт использующий компонент UI kit; у кнопок только с иконкой должны быть доступное имя и область нажатия не меньше 44 × 44 px.
